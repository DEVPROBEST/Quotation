# Analyst Quotation Generator App
ระบบออกใบเสนอราคาสำเร็จรูปสำหรับ บริษัท อนาลิสต์ อินเตอร์เนชั่นแนล จำกัด (ANALYST INTERNATIONAL Co., Ltd.)

## คุณสมบัติ (Features)
- 📝 กรอกข้อมูลใบเสนอราคาบนเว็บ/มือถือ มีระบบคำนวณเงินและ VAT 7% อัตโนมัติ
- 🇹🇭 แปลงตัวเลขราคารวมเป็นตัวหนังสือภาษาไทยอัตโนมัติ (เช่น หนึ่งแสนห้าหมื่นบาทถ้วน)
- 📄 พิมพ์และดาวน์โหลดเอกสาร PDF รูปแบบมาตรฐาน A4 เลย์เอาต์ FP-SA-01-02 Rev.00
- 🌐 รองรับการเปิดใช้งานบน GitHub Pages ฟรีตลอด 24 ชั่วโมง

## โครงสร้างไฟล์ (File Structure)
- `index.html` : หน้าเว็บแอปพลิเคชันหลัก
- `style.css` : สไตล์การจัดรูปเล่ม A4 สำหรับแสดงผลและพิมพ์ PDF
- `app.js` : ระบบสคริปต์คำนวณเงินและแปลงตัวเลขเป็นตัวหนังสือไทย

## วิธีเปิดใช้งานบน GitHub Pages
1. ไปที่ **Settings** ของ Repository นี้
2. เลือกเมนู **Pages** ด้านซ้าย
3. ในส่วน **Build and deployment** เลือก Source เป็น **Deploy from a branch**
4. เลือก Branch เป็น **`main`** / Folder **`/(root)`** แล้วกด **Save**
5. รอ 1-2 นาที เว็บไซต์จะพร้อมใช้งานผ่าน URL: `https://<username>.github.io/<repo-name>/`
